# CIS konnekt

Кликабельное демо хаба тусовок для Санкт-Петербурга. Полностью на Supabase:
события, организаторы, друзья, промоутеры, статистика и личные данные
пользователя (баллы, «Иду», открытые коды) — всё в базе данных, ничего не
хранится в localStorage браузера. Вход — по email и паролю (Supabase Auth);
Кабинет организатора тоже требует входа — один аккаунт управляет одним
организатором.

**Опубликованная версия:** https://cis-konnekt.vercel.app

---

## Как запустить локально

Нужен Node.js (уже установлен на этом компьютере через nvm). Нужен файл
`.env.local` с доступом к Supabase — он уже настроен на этом компьютере
и не хранится в git (см. `.env.local` в папке проекта, если нужно его
содержимое).

```bash
cd ~/Desktop/cis-konnekt
npm install
npm run dev
```

Открыть в браузере: **http://localhost:3000**

Чтобы остановить — `Ctrl+C` в терминале, где запущен `npm run dev`.

## Где что менять

| Что хочешь поменять | Где |
|---|---|
| События, организаторы, друзья | Supabase → Table Editor (или SQL Editor), таблицы `events`, `organizers`, `friends` |
| Название приложения и цвета | `src/config/brand.ts` |
| Любой текст в интерфейсе (кнопки, подписи, сообщения) | `src/content/ru.ts` |
| Список районов для фильтра | `src/data/districts.ts` |
| Список жанров и их цвет на обложке | `src/data/genres.ts` |

Изменения в Supabase видны сразу всем, кто открывает сайт — без
пересборки и без `git push`. Файлы вроде `brand.ts`/`ru.ts` меняются
только через код и публикацию.

### Как поменять дизайн (неоновая тема)

Весь внешний вид — тёмный фон, неоновые цвета, шрифты — собран в
несколько файлов. Трогать остальной код не нужно: поменяешь эти файлы —
подхватится само везде, где используется.

| Что хочешь поменять | Где |
|---|---|
| Основные цвета (фон, акценты, градиент кнопок) | `src/config/brand.ts` — там же комментарии, что за что отвечает |
| Шрифты (заголовки/обычный текст) | `src/app/layout.tsx` — ищи `Unbounded` (заголовки) и `Onest` (обычный текст) |
| Свечение (неоновые тени) и фоновый узор/зерно | `src/app/globals.css` |
| Узоры на обложках событий по жанру | `src/data/genres.ts` |

В `brand.ts` два главных акцентных цвета — `accent` (сейчас розовый,
используется чаще: активная вкладка, кнопки, ссылки) и `accent2`
(сейчас фиолетовый, используется реже: кнопка «Иду», бейдж «сегодня»,
бонусы). Поменяешь эти два hex-кода — поменяется цвет сразу везде в
приложении, искать и менять ничего по отдельным страницам не нужно.

События, созданные или отредактированные через **Кабинет**, тоже сразу
сохраняются в Supabase — видны с любого устройства, и «Сбросить
демо-данные» в профиле на них не влияет (он сбрасывает только личные
данные — баллы, «Иду», открытые коды).

**Фото обложки события** (необязательное поле в форме кабинета) —
загруженное фото сжимается прямо в браузере и загружается в Supabase
Storage (бакет `event-covers`); в карточке события сохраняется только
ссылка на файл. Если фото не загружать — обложка остаётся текстовой, как
у демо-событий.

## Как обновить опубликованный сайт

Сайт на Vercel сам пересобирается при каждом изменении кода на GitHub.
Чтобы обновить сайт:

```bash
cd ~/Desktop/cis-konnekt
git add -A
git commit -m "описание того, что поменял"
git push
```

Через минуту-две изменения появятся на https://cis-konnekt.vercel.app
— следить за сборкой можно в личном кабинете на vercel.com (раздел
Deployments).

## Сценарий показа демо (на 2 минуты)

1. **Открыть ленту, выбрать фильтр** — например, жанр «Техно» или
   вкладку «Выходные».
2. **Профиль** → зарегистрироваться (имя, email, пароль) — показать,
   что сразу появился личный баланс баллов.
3. **Открыть любое событие**, нажать **«Иду»** и **«Купить билет»**
   (или «Записаться», если бесплатное) — показать, что начислились
   баллы (+50), и это видно в профиле.
4. **Профиль → «Код закрытого ивента»** — ввести код `RAVE08`, открыть
   закрытый ивент «Закрытый техно-рейв», посмотреть его полностью.
5. **Кабинет** → (если организатора ещё нет — создать его, указав
   название) → **«Создать событие»** — заполнить и сохранить, показать,
   что оно сразу появилось в ленте. Затем добавить промоутера по
   имени — приложение сгенерирует код и ссылку.
6. **Скопировать промо-ссылку**, открыть её (как будто ты гость),
   нажать **«Купить билет»** — вернуться в кабинет и показать, что
   счётчик кликов у этого промоутера увеличился.
